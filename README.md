# 🛒 Customer Shopping Behaviour Analysis

## 📌 Project Overview
This project analyzes **customer shopping patterns** using **SQL, Python, and Power BI**.  
The goal is to understand customer preferences, spending habits, and product trends to help businesses make **data-driven decisions**.

## 🎯 Objectives
- Identify top-selling products and categories.
- Analyze customer demographics (age, gender, location).
- Study seasonal and monthly sales trends.
- Measure the impact of ratings/reviews on purchases.
- Build interactive dashboards for visualization.

## 🛠️ Tech Stack
- **SQL** → Data storage, queries, aggregation, segmentation.  
- **Python** → Data cleaning, analysis, visualization, machine learning.  
- **Power BI** → Interactive dashboards and business insights.  

## 📂 Dataset
Sample dataset includes:
- `CustomerID`
- `Age`, `Gender`, `Location`
- `Item Purchased`
- `Purchase Amount`
- `Review Rating`
- `Date of Purchase`

*(Dataset can be sourced from Kaggle or synthetic data generated for testing.)*

## 🔧 Workflow
1. **Data Collection & Storage**  
   - Import dataset into SQL database.  
   - Perform queries for sales, ratings, and segmentation.  

2. **Python Analysis**  
   - Connect SQL → Python using `mysql.connector` / `SQLAlchemy`.  
   - Use Pandas, NumPy, Matplotlib, Seaborn for analysis.  
   - Apply clustering (K-Means) to group customers.  
   - Generate insights on spending behavior.  

3. **Power BI Dashboard**  
   - Import cleaned dataset.  
   - Create visuals: bar charts, pie charts, heatmaps, KPIs.  
   - Build interactive dashboard for business users.  

## 📊 Example Insights
- Top 5 most purchased products.  
- Age group with highest spending.  
- Seasonal trends in sales.  
- Correlation between ratings and purchase frequency.
